# Kampüs Etkinlikleri - Sprint 4

Canlı Demo: https://kampus-etkinlik-gray-alpha.vercel.app/

## Proje Yapısı ve Dosyalar
- `src/types/campus-event.ts`: Etkinlik veri tiplerini (CampusEvent) ve kategorileri tanımlar.
- `src/data/events.ts`: 6 adet kampüs etkinliğinin tipli verisini barındırır.
- `src/utils/filter-events.ts`: Arama, kategori filtreleme ve ID ile bulma saf fonksiyonlarını içerir.
- `src/App.tsx`: 5 farklı sayfayı (Ana Sayfa, Etkinlikler, Detay, Ekle, Güncelle) state ile yöneten ana React bileşenidir.
- `src/App.css`: Sprint 3'ten taşınan özel öğrenci stili ve genel düzen CSS kodları.
